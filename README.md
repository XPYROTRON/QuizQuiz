# Quiz? Quiz 2.0

Neon-Quizshow-Spiel für Linux mit GTK4, SQLite, 20.000 Fragen, Kategorien, Joker, Sounds und Konzentrationsmusik mit Herzschlag.

## Start ohne Installation

```bash
sudo apt update
sudo apt install -y python3 python3-gi gir1.2-gtk-4.0 libgtk-4-1 pulseaudio-utils
./run.sh
```

## Nach .deb Installation

```bash
quizquiz
```

Die App erscheint im Ubuntu App-Grid als **Quiz? Quiz**.
